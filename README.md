# 전자동기계광고

산업기계·중고기계 **공급사와 고객을 연결하는 기계 광고 플랫폼**입니다.
여러 공급사가 한 사이트에 제품을 올리고, 고객은 통합 검색·카테고리에서 제품을 찾아 공급사에 바로 전화·문자로 문의합니다.

## 주요 기능
- **통합 제품 검색 · 카테고리**: 1차 → 2차 공통 분류, 분류 번호 주소(`/products?cate_no=1`)
- **공급사 미니샵**: 공급사마다 미니샵(`/s/공급사주소`), 배너, 홈페이지 템플릿, 공급사 카테고리
- **상품 상세**: 대표·추가 이미지, 신품·중고·직접거래 아이콘, 연식·원산지, 전화·문자·공유·QR 문의, Q&A
- **광고**: 배너 관리(그룹·배너 코드·백업), 메인 슬라이드 A/B 타입, 허브 광고, 유료 상단 노출, 노출·클릭 통계
- **운영**: 공급사 입점 신청·승인, 콘텐츠(쇼츠·블로그·매거진), 사이트 설정, 광고 성과, 검색엔진 최적화(사이트맵·구조화 데이터)

## 기술
Next.js 15 (App Router) · Supabase (Postgres · Auth · Storage · RLS) · Tailwind CSS v4 · TypeScript

## 개발
```bash
npm install
npm run dev
```
- 환경변수는 `.env` 파일에 넣습니다. 목록은 [docs/배포-안내.md](docs/배포-안내.md)를 보세요.
- DB 변경은 `supabase/migrations/` 의 SQL을 번호 순서대로 Supabase SQL 편집기에서 실행합니다.
- 품질 확인: `npx tsc --noEmit`, `npm run build`
