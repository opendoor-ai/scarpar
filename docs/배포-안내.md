# 전자동기계광고 배포 안내 (Vercel)

인터넷에 실제 주소로 공개하는 방법입니다. 한 번만 설정하면, 이후에는 GitHub에 올릴 때마다 자동으로 다시 배포됩니다.

## 0. 배포 전 확인 (완료 여부 체크)

- [x] 실제 배포용 빌드 검사 통과 (`npm run build`)
- [ ] Supabase SQL `0001` ~ `0019` 모두 실행
- [ ] 관리자 화면 **사이트 설정**에 사업자 정보 확인 (0019 실행 시 jadong.co.kr 정보로 채워짐)
- [ ] **광고 관리**에 메인 배너 몇 개 등록 (광고가 없는 칸은 화면에 안 보임)

## 1. Vercel 가입·연결 (직접 하셔야 해요)

1. https://vercel.com 에 들어가 **GitHub 계정으로 가입**합니다. (무료 Hobby 요금제로 시작 가능)
2. **Add New → Project** → GitHub 저장소 목록에서 `opendoor-ai/scarpar`를 **Import** 합니다.
3. Framework는 자동으로 **Next.js**가 잡혀요. 다른 설정은 그대로 둡니다.

## 2. 환경변수 넣기 (Import 화면의 Environment Variables)

내 컴퓨터의 `.env` 파일에 있는 값을 그대로 옮겨 적습니다. **이 값들은 비밀번호와 같으니 채팅·카톡 등에 붙여넣지 마세요.**

| 이름 | 값 | 필수 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase 프로젝트 주소 | 필수 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase anon(공개) 키 | 필수 |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase service_role 키 (서버 전용 비밀값) | 필수 |
| `NEXT_PUBLIC_APP_URL` | 배포된 주소 (처음엔 `https://프로젝트이름.vercel.app`, 도메인 연결 후 `https://jeonjadong.com`) | 필수 |
| `NEXT_PUBLIC_ROOT_DOMAIN` | `jeonjadong.com` — 넣으면 미니샵이 `공급사아이디.jeonjadong.com` 주소로 열려요 (5번 도메인 연결을 마친 뒤에 넣기) | 선택 |
| `NEXT_PUBLIC_SITE_NAME` | `전자동기계광고` (안 넣어도 기본값) | 선택 |
| `ANTHROPIC_API_KEY` | AI 상품 문구용 키 (발급 후) | 선택 |
| `NEXT_PUBLIC_AUTH_KAKAO`, `NEXT_PUBLIC_AUTH_NAVER` | 간편로그인 켤 때 `true` | 선택 |
| `NEXT_PUBLIC_NAVER_SITE_VERIFICATION`, `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` | 네이버·구글 검색 등록 확인 코드 | 선택 |

## 3. Deploy 누르기

몇 분 뒤 `https://프로젝트이름.vercel.app` 주소가 생깁니다.

## 4. 배포 후 꼭 할 일

1. **`NEXT_PUBLIC_APP_URL`을 실제 주소로** 바꾸고 Vercel에서 **Redeploy** 합니다.
2. **Supabase → Authentication → URL Configuration**
   - Site URL: 배포 주소
   - Redirect URLs: `배포주소/auth/callback` 추가 (로그인·간편로그인이 돌아오는 주소)
3. 휴대폰으로 접속해서 **전화·문자 버튼**이 실제로 되는지 확인합니다.
4. 네이버 서치어드바이저·구글 서치콘솔에 사이트를 등록하고 `배포주소/sitemap.xml`을 제출합니다.

## 5. 도메인 연결 — jeonjadong.com + 공급사 서브도메인 (공급사아이디.jeonjadong.com)

공급사가 생기면(공급사 생성·등록 승인) **따로 할 일 없이** `공급사아이디.jeonjadong.com` 이 바로 열려요.
이를 위해 처음 한 번만 아래를 해 둡니다.

1. **도메인 네임서버를 Vercel로 바꾸기** — 와일드카드(`*.jeonjadong.com`) 보안 인증서는 Vercel 네임서버일 때만 자동 발급돼요.
   - Vercel 프로젝트 → **Settings → Domains** → `jeonjadong.com` 추가 → 안내되는 네임서버 2개(`ns1.vercel-dns.com`, `ns2.vercel-dns.com`)를
     도메인 산 곳(가비아·후이즈 등)의 **네임서버 설정**에 넣어요. (반영까지 몇 시간~하루)
   - 메일 등 다른 DNS 기록이 있었다면 Vercel의 DNS 화면에 똑같이 다시 넣어야 해요.
2. 같은 Domains 화면에 **`*.jeonjadong.com`** 과 **`www.jeonjadong.com`** 도 추가해요.
3. 환경변수: `NEXT_PUBLIC_APP_URL` = `https://jeonjadong.com`, `NEXT_PUBLIC_ROOT_DOMAIN` = `jeonjadong.com` → **Redeploy**.
4. Supabase → Authentication → URL Configuration 의 Site URL·Redirect URLs 를 `https://jeonjadong.com` 기준으로 바꿔요.
   (로그인·관리자는 항상 대표 주소 jeonjadong.com 에서 열려요. 공급사 미니샵의 /admin 은 자동으로 대표 주소로 넘어가요.)

동작 방식: `src/middleware.ts` + `src/lib/domains.ts`. 예전 주소 `jeonjadong.com/minishop/아이디/...` 는 새 주소로 자동 이동해요.
공급사 아이디로 쓸 수 없는 이름(www, admin, mail 등)은 `RESERVED_SLUGS` 에서 막아요.

## 6. (참고) 기존 jadong.co.kr
